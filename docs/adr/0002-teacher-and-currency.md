# Teacher-led Learning and optional Classic supplies

Teacher-directed use is the normal context. Learning remains free of forced shops
and run modifiers. Classic supplies use run stars and expire with the run; saved
stars remain cosmetic currency. Legacy purchases must not be erased during this
change. They remain recorded, but permanent Classic advantages are no longer
silently applied to new runs. This deliberately separates practice from roguelite
resource management and avoids accidental pay-to-win assumptions.
