with --repo explicitly. Never put secrets, student data or private screenshots in
this public tracker. External PRs as requests: no.

 docs/tickets/WW-NNN.md are versioned initial briefs/offline snapshots, not a second
tracker. docs/STATUS.md is a dated short resume view with issue links.

claiming the live game is fixed. Reopen if verification later disproves completion.
