# Labels

bug / enhancement = category. needs-triage = unshaped backlog; needs-info = blocked
on a decision or reproduction; ready-for-agent = implementation contract ready;
in-progress = claimed; ready-for-human = precise manual/external check needed;
wontfix = rejected with reason. Keep one active state label. GitHub closed plus
completion evidence means done, not another permanent status label.

priority:p1 = assessment/core-flow first; priority:p2 = important coherence and
learning/usability; priority:p3 = expansion/polish. No current QA issue is P0.
ai:astra / ai:sol / ai:terra / ai:gemini = recommended model, not exclusive owner.
planning-only = design/prototype scope, never automatic permission to edit gameplay.
Read body dependencies: needs-info also covers a blocking prerequisite ticket.
An actual worker claims in a comment after the pre-edit model-mismatch notice.
